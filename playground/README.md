# Playground

TypeScript experiments. Run any file with:

```bash
npx tsx src/filename.ts
```

Files here are personal scratchpads — not deployed, not part of the app.
Interesting solutions get moved to `docs/typescript/` or the `/challenges` page.

## Structure

```
src/
  01-types/         # Union types, type guards, utility types
  02-generics/      # Generic functions and constraints
  03-async/         # Promises, async/await, fetch patterns
  04-patterns/      # Closures, OOP, modules
  05-react-ts/      # React-specific TypeScript patterns
```
