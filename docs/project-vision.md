# Project Vision

## Mission

A personal laboratory for React mastery, Design Systems, and interview preparation.
Built in public. One session at a time.

## Who sees this

**Recruiters** — React, TypeScript, component architecture, documentation, real git history.  
**Future clients** — design sensibility, structure, how I think about product.  
**Myself** — learning record, confidence builder, evidence of growth.

## Three tracks — one project

| Track | Where it lives | Frequency |
|---|---|---|
| React + UI Engineering | zorich-lab build sessions | 2x week, 90 min |
| TypeScript + DSA | `/challenges` page + docs | 3x week, 45 min |
| System Design | `/docs/architecture` ADRs + reading | 1x week, 45 min |

## Month 1 goals

- [ ] Monorepo running locally with Next.js 15 + TypeScript
- [ ] Deployed to zorich-lab.vercel.app
- [ ] Design tokens defined (colors, spacing, typography)
- [ ] 3 components built and documented: Button, Input, Card
- [ ] `/ui` page live showing components with usage examples
- [ ] `/challenges` page live with first 3 TypeScript snippets
- [ ] First architecture decision recorded
- [ ] 12 LeetCode problems completed (tracked in docs)

## Constraints

- No CMS, no database, no auth yet
- Freelancing is not a current goal — stability first
- Every new idea goes to backlog, not into the build
- elenazorich.dev is the target domain — zorich-lab.vercel.app until ready

## The name

zorich-lab — a laboratory, not a studio. Labs are allowed to be in progress.
